# data-provenance.md — 出題データの出典と執筆方針

`data/tracks/*.json` の全エントリ(2026-08-12 時点で 3 トラック × 150 = 450 件)の
出典・著作権・執筆規約の正本。データ規約の上位文書は SPEC §5。

## cmd(出題文字列)

コマンド名・関数名・API 名・キーワード(`grep` / `str.split` / `Promise.all` 等)は
公知の技術の名称であり、**事実**として使用している。名称そのものは著作権の保護対象ではなく、
学習アプリにおける記述的使用のため商標上も問題にならない。

## desc(解説文)

全件が本プロジェクトのために書き下ろした**オリジナルの日本語文**(8〜40 文字)であり、
既存文書からの転載・翻訳・要約引用は行っていない。したがって man-pages(GPL 等)、
MDN(CC BY-SA)、Python 公式文書(PSF License)等の第三者ライセンスの義務
(ライセンス継承・帰属表示)は発生せず、リポジトリの MIT ライセンスで公開できる。

執筆: リポジトリ所有者と Claude(Anthropic)の協働による書き下ろし
(loop_000〜016。ループログ `logs/loops/` に記録)。

## 正確性の参照先(正本とする公式ドキュメント)

解説文の記述内容に疑義が生じた場合は、以下を正として確認し、
`data:` コミットで修正する(配分に影響する場合はスペック改訂から)。

| track | 参照先 |
|---|---|
| linux | 各コマンドの man ページ、GNU coreutils マニュアル |
| python | docs.python.org(公式リファレンス) |
| typescript | MDN Web Docs(JS 標準 API)、TypeScript Handbook(型システム) |

参照は**事実確認のみ**とし、文章表現を写さないこと(SPEC §5 の転載禁止)。

## 今後の執筆規約

1. 新規エントリの `desc` は必ず書き下ろす。既存文書のコピー・翻訳・語順入替は不可
2. 不確かな挙動は上表の公式ドキュメントで確認してから書く(AGENTS §5)
3. 名称の採録は事実の範囲にとどめ、ロゴ画像等のブランド資産は取り込まない
   (トラック基調色は SPEC §7.1 — 色自体は著作権保護の対象外)
